01 · Mac + iPhone

PhonePad

My iPhone as a trackpad and keyboard for my Mac. No account, no app store, no subscription.

Web app Runs locally Built with Claude
The problem

Every remote mouse app I tried wanted a monthly subscription for something simple: move the cursor and type from my phone when I'm across the room from my Mac.

What I built

A small web app that runs on my Mac. I start it with one double-click, open the page on my iPhone over Wi-Fi, and the phone becomes a trackpad with a keyboard.

How I got there

I kept it as simple as possible: a local server on the Mac and a single page on the phone. No install on the phone at all, which also means nothing to update.

What's next

A three finger swipe to switch between full screen apps, and an option to play the Mac's audio through the phone.

02 · Chrome + Mac

Floating Shorts player

YouTube Shorts in a floating window that stays on top of everything, even full screen apps, with real controls.

Chrome extension Native Mac app Open source fork
The problem

The picture in picture apps that do this well are paid, and the free ones don't give you next, previous or skip controls. I wanted to scroll Shorts in a corner while I work without touching the browser.

What I built

A fork of the open source FullFloatPiP extension and its Mac app. I added on-screen previous and next buttons, adjustable skip back and forward, play and pause, and global hotkeys I can set myself, like Cmd+Shift+Down for the next Short.

How I got there

Instead of starting from zero, I found the best open source base and built on it. The extension handles YouTube, and the Mac app is what lets the window float over full screen apps.

What's next

A clean version anyone can install from the Chrome Web Store, likely extension only at first so it doesn't need the Mac app.

03 · Chrome Web Store

Chrome extensions

My own versions of popular paid extensions, sold for a small one-time price instead of a monthly fee.

In progress One-time pricing
The problem

A lot of popular extensions do one small job and charge every month for it. That adds up, and most people would rather pay once.

The plan

Rebuild them one at a time, starting with the floating Shorts player. Each one gets a free trial, then a low one-time payment.

How I'm approaching it

Build each for myself first and use it daily. Only the ones that hold up get cleaned up and published.

What's next

Once there are enough of them, a simple site to host them all in one place.
