What it does

Waiver board

Ranks pickups for my Sleeper leagues by expected points, usage trends and matchups.

Lab

Query every nflverse stat in the browser: pivots, a DuckDB SQL editor, charts and CSV export.

Pressers

Head coach press conferences pulled daily and summarized with Claude, so injury and role news shows up in one place.

The Rundown

Weekly recap and preview articles for my league, written by Claude from the week's real stats.

Trade and matchups

League and NFL matchups side by side, plus a trade view for comparing players.

Stat guide

A plain-English guide to the roughly 1,500 nflverse stat columns.

Getting Yahoo API access approved

Sleeper has an open API. Yahoo doesn't. To bring Yahoo leagues into the site, I had to apply to Yahoo for Fantasy Sports API access and get the use case approved.

  1. Applied (Oct 2026)Requested Fantasy Sports API access so friends in Yahoo leagues could use the site with their own leagues.
  2. Approved for personal use (Nov 2026)Yahoo approved the app and I signed their API agreement.
  3. Asked for more (Nov 2026)Emailed Yahoo to ask whether friends could connect their leagues and whether full league rosters were allowed.
  4. Confirmed (Nov 24, 2026)Yahoo confirmed my access under the same agreement.
  5. Built the private Yahoo pageA login-only "My Yahoo team" page running on a Cloudflare Worker behind Cloudflare Access.
